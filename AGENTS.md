# Pi Package index

Description: Points to INDEX.md files for navigating this Pi workflow package; index-only navigation map.

Instructions:
1. Prefer the default and natively built-in Pi Coding Agent TUI APIs and functionality when asked to build TUI, where possible.
2. Use INDEX.md files to navigate the codebase.

Components:

- `extensions/blink/INDEX.md` — Blink human file-review modes and the tmux/Neovim review protocol.
- `extensions/ctx/INDEX.md` — context inspection UI, anchor jumps, and the fresh-session workflow.
- `extensions/muon/INDEX.md` — Muon modes, skill management, resource discovery, and skillsets.
- `extensions/olive-agents/INDEX.md` — autonomous sub-agents: lifecycle, tmux windows, mailbox, context handoff.
- `extensions/pi-telescope/INDEX.md` — fuzzy finder UI and its providers.
